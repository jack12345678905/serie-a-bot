Questo programma serve a mandare su un bot telegram le partite del fine settimana.
All'interno di github sono inserite delle chiavi che corrispondono al token per interagire con il bot, l'ID della chat di gruppo in cui è stato inserito il bot e l'API per fare la richiesta al server per carpire le informazioni.
Il link dove vengono fatte le richieste è il seguente: https://www.football-data.org/
